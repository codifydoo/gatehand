# Security policy

Please report vulnerabilities privately through GitHub:
[Report a vulnerability](https://github.com/codifydoo/gatehand/security/advisories/new).
Do not open a public issue for a security problem.

Fixes go into the latest release on `main`; older versions are not patched.

Gatehand's security model and its known residual risks are described in
[`docs/README.md`](docs/README.md). A report that shows one of those risks is worse than described
there is in scope too.
